## 「不限流量」这四个字，三家用三种意思

LightLayer、Wolkra、VerticHost 的套餐表里都写着不限流量或 unmetered，实际含义并不一致。

Wolkra 写的是 unmetered traffic，配 fair use 条款，端口最高 10Gbit/s 共享。VerticHost 写所有套餐 unmetered，没有附加条件。Scopehosts 的说明最细：入站流量在合理使用下不计，出站流量取决于你选的流量方案，高配档标 Unmetered 时带星号。

LightLayer 的云服务器三档写 Unlimited data，伦敦 VPS 那条线反过来标了明确的 1TB/月。

看「不限」两个字没意义，要看两项：出站给多少、端口多大。跑视频、做下载站、挂 CDN 回源，出站和端口速率决定实际体验；普通企业站一个月跑几十 GB，1TB 和「不限」对你没区别。

## 账单上容易被忽略的四项

**IPv4 单独收费。** Wolkra 的套餐默认只含 IPv6，IPv4 每月 €0.89。一条 VPS 跑一年，这项就是 €10.68 的额外支出。下单页要看清楚 IPv4 是含在套餐里还是要加购。

**关机不等于停止计费。** LightNode 的 FAQ 里写得很明确：关闭 VPS 会停止服务器运行，但资源仍被占用，账单继续按合同计费，要停止计费必须释放实例。按小时计费的厂商大多是这个逻辑，临时不用几天就关机的习惯在这里省不了钱。

**年付折算价冒充月付价。** Scopehosts 的表格里价格写成「€ X /monthly*」带星号，点进去所有下单链接都挂着按年付的计费参数。判断方法很简单：看下单按钮的链接里有没有计费周期参数，有 annually 就是年付价。真要月付，得在购物车里手动改周期，价格会变。

**磁盘只能扩不能缩。** Wolkra 明确写了磁盘扩容不可逆，建议从小档起步。买了 80GB 想退回 40GB 通常要重装系统重建实例。第一次选配置时留一点余量比事后缩容省事。

欧洲厂商报价普遍不含 VAT，€3.49 和 €8.99 这类数字是税前价，欧盟境内客户结算时会加上当地税率，具体以结账页显示为准。

## 谁不适合买欧洲 VPS

用户主要在中国、东南亚、北美或南美，欧洲机房就是绕路。Wolkra 自己在适用场景表里写了这一条：用户主要在亚洲或美洲，应该找有当地机房的厂商。加 CDN 只能解决静态文件的就近分发，数据库查询、API 请求、登录验证这些动态请求照样要跨洲往返，延迟躲不掉。

另一种不适合的情况是预算极紧又要高配。欧洲入门档 €3.49 能给到 1GB 内存，但这个价位买不到原生 IP、独享带宽和技术支持响应。需求里带「原生 IP」「英国本地」「多 IP」这些条件，预算就得按 $19 起算。
